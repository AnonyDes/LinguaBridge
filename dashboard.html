Desktop extension · Prototype

LinguaBridge for Google Chrome

Read balances, payment instructions, fees and security messages in a familiar language. The extension works alongside existing websites. Duala and Ewondo translations are being developed and reviewed.

Get the prototype extension

Get started in 3 steps

  1. Download the latest build artifact from GitHub Actions and extract the archive.
  2. Open chrome://extensions, enable Developer mode, then choose Load unpacked and select the extracted extension folder.
  3. Open a financial website, launch LinguaBridge and select Duala or Ewondo. Check all financial details against the original text before acting.

Prototype for testing. Not a Chrome Web Store or Edge Add-ons release. Do not enter sensitive credentials into demo fields.
