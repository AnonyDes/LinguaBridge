LinguaBridge for Google Chrome

Read balances, payment instructions, fees and security messages in a familiar language. The extension works alongside existing websites. Ewondo and other Cameroonian language packs are being tested and reviewed.

Download for Google Chrome

In the latest successful workflow run, open Artifacts and download LinguaBridge-Google-Chrome. Both browsers use the same Chromium extension code, packaged separately for clarity.

Get started in 3 steps

  1. Download the latest successful LinguaBridge-Google-Chrome artifact from GitHub Actions, then extract the ZIP file.
  2. Open chrome://extensions, enable Developer mode, then choose Load unpacked and select the extracted folder containing manifest.json. Remove any previous LinguaBridge version to avoid duplicates.
  3. Open a financial website, click the LinguaBridge icon in the browser toolbar, select your target language and use the Traduction or Assistant tab. The source language is detected automatically. Check financial details against the original text before acting.

Prototype for testing. Not a Chrome Web Store or Edge Add-ons release. Do not enter sensitive credentials into demo fields.
