Your money. Your language.

Financial services should be understandable to everyone. LinguaBridge helps translate banking, mobile money and payment interfaces from French or English into Ewondo, Fulfulde, Haoussa, Kanuri and Cameroon Pidgin, starting with a desktop browser extension. Our goal is to make the same accessibility available on mobile and through the web.

02 / SAFETY FIRST

Understand the message. Preserve the numbers.

Financial translation must protect what matters: amounts in FCFA, fees, account references, telephone numbers and beneficiary details.

Built for financial information

LinguaBridge is designed to identify and preserve sensitive financial values when translating interface text. A translation should never silently change the amount being sent or the destination number.

Privacy and responsible testing

We aim to minimize the financial information processed. The current prototype is for testing: verify the original message before completing a transaction, and never enter passwords or PINs into the demo.

01 / INSTALL

Add LinguaBridge to your browser

Download the current prototype build from GitHub Actions. Extract the archive, then open chrome://extensions or edge://extensions, enable Developer mode and select “Load unpacked”.

Explore extension access

Desktop Chrome and Edge prototype. Web and mobile access are planned, not yet released.

02 / TRANSLATE

Choose your language and browse

On desktop, visit a banking, mobile money or payment website. Open LinguaBridge, select an available Cameroonian language and translate interface text from French or English. The extension is designed to work without changes to the original website.

Translation coverage is still being tested. Always check amounts, fees, account details and security warnings against the original before acting.
